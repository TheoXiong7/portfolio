1 · make a token

Create a fine-grained personal access token. Repository access: only TheoXiong7/portfolio. Permissions: Contents · read and write, nothing else. Pick an expiry; you'll come back here to re-seal when it lapses.

2 · choose a passphrase

The sealed file is public, so anyone can download it and guess offline at a few thousand tries per second per GPU. That's harmless when the passphrase is long and random: use the generator, or five or more random words. Never a reused password.

3 · seal

Derives a key from the passphrase (PBKDF2-SHA256, 600k rounds) and encrypts the token with AES-256-GCM.

save this as static/files/betterMDshare/vault.json, commit, push. from then on the app unlocks with the passphrase from any browser.

how this holds up
  • Nothing secret is in the site's code. The only secret is the passphrase in your head; the token exists in plaintext only in the browser session that unlocked it.
  • What the token can do if it ever leaks: push commits to this one repo until it expires or you revoke it at github.com/settings/personal-access-tokens.
  • A generated passphrase has ~79 bits of entropy. At 600k PBKDF2 rounds that's on the order of a billion GPU-years to exhaust, so the vault being public is fine.
  • To rotate: make a new token, seal it here, replace vault.json, revoke the old token.
